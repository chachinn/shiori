# Shiori 🌸

Mobile-first Japan travel companion for Cha + Martin's **Oct 18–25, 2026** trip.

## Current modules

- Days 1–8 itinerary
- Transport guide
- Reservation / ticket tracker
- Full trip budget
- Packing checklist for Cha, Martin, and shared items
- Visa / immigration document reference
- Planning inbox / items to add
- Per-stop checkboxes and personal day notes saved locally on the device
- PWA manifest + offline service worker

## Update workflow

The Google Sheet remains the detailed planning/reference archive. When the itinerary changes, update the relevant Sheet tabs **and** the Shiori app data so both stay aligned.

## Deployment

Shiori is a static PWA and can be deployed from the repository root using GitHub Pages.
